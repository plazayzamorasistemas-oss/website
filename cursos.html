Cursos de Programación Android

Requisito: El curso Introducción a la programación con Android (20 horas).

Tecnologías Microsoft .NET

Todos los cursos hacen uso intensivo de herramientas de IA para adecuarse a los nuevos procedimientos en desarrollo de software.

Cursos disponibles (haz clic para ver detalles):

Objetivo: Comprender los fundamentos de la programación orientada a objetos y el desarrollo de aplicaciones de escritorio utilizando el lenguaje Visual Basic .NET y el entorno de Visual Studio.

Requisito: Para todo público. NO se requiere experiencia en programación..

Contenido:

  • Módulo 1: Introducción al Entorno y Sintaxis (10h): Estructura de Visual Studio, tipos de datos, variables, operadores y estructuras de control de flujo (condicionales y bucles).
  • Módulo 2: Programación Orientada a Objetos en VB.NET (10h): Clases, objetos, herencia, encapsulamiento, polimorfismo y manejo de excepciones.
  • Módulo 3: Desarrollo de Interfaces de Usuario (Windows Forms) (10h): Uso de controles estándar (botones, cuadros de texto, tablas), gestión de eventos y creación de formularios múltiples.
  • Módulo 4: Desarrollo de una aplicación de escritorio completa con persistencia básica de datos (10h).

Objetivo: Dominar el lenguaje C# y las características esenciales del framework .NET para construir aplicaciones robustas, escalables y orientadas a objetos.

Requisito: El curso Introducción a la programación con Visual Basic .NET (40 horas).

Contenido:

  • Módulo 1: Fundamentos de C# (10h): Sintaxis básica, tipos de valor y referencia, arreglos, colecciones y manejo seguro de errores con bloques try-catch.
  • Módulo 2: POO Avanzada en C# (10h): Principios de diseño orientado a objetos, interfaces, clases abstractas, delegados y expresiones LINQ para consultas de datos.
  • Módulo 3: Programación Asíncrona y Entrada/Salida (10h): Uso de hilos, tareas asíncronas con async/await y lectura/escritura de archivos locales.
  • Módulo 4: Proyecto Integrador (10h): Creación de una aplicación modular en consola o escritorio aplicando buenas prácticas de código limpio.

Objetivo: Diseñar y desarrollar aplicaciones web dinámicas y seguras del lado del servidor utilizando la arquitectura y las herramientas de ASP.NET.

Requisito: El curso Introducción a la programación con Visual Basic .NET (40 horas).

Contenido:

  • Módulo 1: Introducción al Desarrollo Web y ASP.NET (10h): Arquitectura cliente-servidor, protocolo HTTP, modelo de ciclo de vida de páginas y uso de ASP.NET Core MVC o Web Forms.
  • Módulo 2: Gestión de Vistas y Formularios Web (10h): Creación de interfaces responsivas con HTML/CSS integradas al servidor, validación de datos y paso de información mediante controladores.
  • Módulo 3: Conexión a Bases de Datos con Entity Framework (10h): Mapping objeto-relacional (ORM), consultas LINQ to Entities y operaciones CRUD conectadas a una base de datos SQL.
  • Módulo 4: Autenticación y Despliegue (10h): Gestión de usuarios, seguridad básica, manejo de sesiones y publicación de la aplicación web en un servidor de prueba o producción.

Objetivo: Exponer y consumir servicios web basados en arquitecturas modernas (RESTful APIs) utilizando ASP.NET Core para la integración con sistemas externos.

Requisito: El curso Programación con ASP .NET (40 horas).

Contenido:

  • Módulo 1: Fundamentos de APIs Web (5h): Conceptos de servicios web, verbos HTTP (GET, POST, PUT, DELETE), códigos de estado y formato JSON.
  • Módulo 2: Creación de Web APIs con ASP.NET Core (8h): Configuración de controladores, enrutamiento, inyección de dependencias y serialización de datos.
  • Módulo 3: Seguridad y Consumo de Servicios (4h): Implementación de autenticación basada en tokens (JWT) y pruebas de endpoints mediante la herramienta Postman.
  • Módulo 4: Proyecto Práctico (3h): Desarrollo y consumo de una API RESTful funcional integrada a una base de datos ligera.

Objetivo: Crear aplicaciones multiplataforma nativas (móviles y de escritorio) utilizando una única base de código compartida con .NET MAUI (Multi-platform App UI).

Requisito: El curso Programación con ASP .NET (40 horas).

Contenido:

  • Módulo 1: Fundamentos de .NET MAUI (5h): Arquitectura del framework, configuración del entorno de desarrollo y estructura de proyectos multiplataforma.
  • Módulo 2: Diseño de Interfaces con XAML (7h): Uso de layouts (StackLayout, Grid), controles visuales multiplataforma y enlace de datos (Data Binding).
  • Módulo 3: Navegación y Arquitectura MVVM (5h): Implementación del patrón Model-View-ViewModel, navegación entre páginas y gestión de comandos.
  • Módulo 4: Acceso a Características Nativas (3h): Uso de sensores del dispositivo (geolocalización, cámara) desde la aplicación MAUI.

Objetivo: Desarrollar aplicaciones web interactivas del lado del cliente y del servidor utilizando C# en lugar de JavaScript mediante el framework Blazor.

Requisito: El curso Programación con ASP .NET (40 horas) y el curso Programación con C# .NET (40 horas).

Contenido:

  • Módulo 1: Introducción a Blazor (5h): Modelo de componentes de Blazor, WebAssembly vs. Blazor Server, y configuración del entorno de desarrollo.
  • Módulo 2: Creación de Componentes Interactivos (7h): Desarrollo de interfaces basadas en componentes Razor, manejo de eventos, paso de parámetros y enlace bidireccional de datos.
  • Módulo 3: Enrutamiento, Servicios y Estado (5h): Gestión de rutas, inyección de servicios personalizados y manejo del estado de la aplicación.
  • Módulo 4: Proyecto Práctico (3h): Construcción y despliegue de una aplicación web interactiva de una sola página (SPA) desarrollada íntegramente en C#.

Desarrollo JAVA

Uso intensivo de herramientas de IA para adecuarse a los nuevos procedimientos en desarrollo de software.

Cursos disponibles:

Objetivo: Establecer las bases sólidas de la programación orientada a objetos utilizando el lenguaje Java, abarcando desde la sintaxis fundamental hasta el manejo estructurado de datos.

Requisito: Para todo público. NO se requiere experiencia en programación..

Contenido:

  • Módulo 1: Fundamentos de Java y Sintaxis (10h): Tipos de datos primitivos, operadores, estructuras de control condicionales (if, switch) y bucles (for, while).
  • Módulo 2: Programación Orientada a Objetos (POO) (15h): Clases, objetos, métodos, encapsulamiento, herencia, interfaces y polimorfismo.
  • Módulo 3: Colecciones y Manejo de Errores (10h): Uso de arreglos avanzados, listas, mapas (List, Map), y gestión de excepciones mediante bloques try-catch-finally.
  • Módulo 4: Proyecto Práctico (5h): Consolidación de los conceptos básicos mediante la creación de un sistema de contabilidad básica.

Objetivo: Desarrollar aplicaciones web dinámicas del lado del servidor utilizando la tecnología estándar de Java Servlets y JavaServer Pages (JSP).

Requisito: El curso Introducción a la programación con JAVA (40 horas).

Contenido:

  • Módulo 1: Arquitectura Web en Java (8h): Funcionamiento del protocolo HTTP, ciclo de vida de un Servlet y configuración de servidores de aplicaciones (Apache Tomcat).
  • Módulo 2: Desarrollo con Servlets (8h): Gestión de peticiones y respuestas HTTP (HttpServletRequest, HttpServletResponse), manejo de parámetros y sesiones de usuario.
  • Módulo 3: JavaServer Pages (JSP) (10h): Sintaxis de JSP, uso de etiquetas estándar, expresiones, scripts y separación de la lógica de negocio mediante el patrón Modelo Vista Controlador (MVC).
  • Módulo 4: Proyecto Práctico (4h): Creación de una aplicación web interactiva de inventario con autenticación básica de usuarios.

Objetivo: Diseñar interfaces gráficas de usuario (GUI) robustas para aplicaciones de escritorio en Java utilizando las librerías clásicas AWT y Swing.

Requisito: El curso Introducción a la programación con JAVA (40 horas).

Contenido:

  • Módulo 1: Introducción a interfaces gráficas con AWT y Swing (8h): Diferencias entre componentes ligeros y pesados, contenedores principales (JFrame, JPanel) y jerarquía de componentes.
  • Módulo 2: Gestión de Layouts y Componentes Visuales (10h): Uso de administradores de diseño (BorderLayout, FlowLayout, GridBagLayout) y controles interactivos (botones, tablas, menús, cuadros de texto).
  • Módulo 3: Gestión de Eventos y Escuchas (8h): Programación dirigida por eventos, interfaces ActionListener, MouseListener y validación de formularios interactivos.
  • Módulo 4: Proyecto Práctico (4h): Desarrollo de una aplicación de escritorio de inventario con menús y gestión de tablas de datos locales.

Objetivo: Construir, publicar y consumir servicios web interoperables utilizando tanto arquitecturas basadas en protocolos XML (SOAP) como servicios ligeros basados en recursos (REST).

Requisito: El curso Introducción a la programación con JAVA (40 horas) y el curso Programación WEB con JSP y Servlets (30 horas).

Contenido:

  • Módulo 1: Fundamentos de Interoperabilidad (6h): Conceptos de servicios web, diferencias clave entre arquitecturas orientadas a servicios (SOA) y RESTful.
  • Módulo 2: Servicios Web SOAP en Java (10h): Creación de servicios basados en JAX-WS, contratos WSDL, tipos de datos XML y pruebas de integración.
  • Módulo 3: Servicios Web RESTful con JAX-RS (10h): Diseño de APIs orientadas a recursos, uso de verbos HTTP, códigos de estado y serialización automática de objetos a JSON/XML.
  • Módulo 4: Pruebas y Consumo (4h): Elaborar Servicios Web para manejo de un inventario, y un cliente JAVA que los consuma.

Objetivo: Implementar aplicaciones web estructuradas y modulares utilizando el patrón Modelo-Vista-Controlador provisto por el ecosistema del framework Spring.

Requisito: El curso Introducción a la programación con JAVA (40 horas) y el curso Programación WEB con JSP y Servlets (30 horas).

Contenido:

  • Módulo 1: Fundamentos de Spring y Inyección de Dependencias (8h): Inversión de Control (IoC), contenedores Spring y configuración basada en anotaciones (@Component, @Autowired).
  • Módulo 2: Arquitectura Spring MVC (10h): Funcionamiento del DispatcherServlet, mapeo de solicitudes con controladores (@Controller, @RequestMapping), y paso de modelos a vistas.
  • Módulo 3: Formularios, Validación y Datos (8h): Vinculación de datos en formularios, validación mediante anotaciones estándar (JSR-303) y manejo de excepciones web.
  • Módulo 4: Proyecto Práctico (4h): Construcción de una aplicación de inventario utilizando Spring MVC y vistas interactivas.

Objetivo: Acelerar el desarrollo de aplicaciones empresariales independientes y listas para producción utilizando las convenciones y herramientas de autoconfiguración de Spring Boot.

Requisito: El curso Introducción al framework Spring MVC (30 horas).

Contenido:

  • Módulo 1: Introducción y Configuración Automática (8h): Filosofía de Spring Boot, inicialización de proyectos con Spring Initializr, gestión de dependencias y archivos de propiedades (application.properties/yml).
  • Módulo 2: Desarrollo de APIs y Microservicios (10h): Creación rápida de controladores REST con @RestController, gestión de mapeos HTTP y manejo global de errores.
  • Módulo 3: Persistencia de Datos con Spring Data JPA (8h): Conexión a bases de datos relacionales, uso de repositorios JPA, entidades y operaciones CRUD simplificadas sin código boilerplate.
  • Módulo 4: Pruebas y Despliegue (4h): Pruebas unitarias de componentes y empaquetado de la aplicación en un archivo ejecutable listo para producción.

Requisito: El curso Introducción a la programación con JavaScript (40 horas).

Contenido:

  • Módulo 1: Introducción a Node JS y Módulos (8h): Arquitectura asíncrona orientada a eventos, gestión de paquetes con NPM y uso de módulos nativos del sistema.
  • Módulo 2: Desarrollo Backend con Express (10h): Configuración de servidores web, gestión de rutas, uso de middlewares y procesamiento de peticiones HTTP (GET, POST, PUT, DELETE).
  • Módulo 3: Conexión a Bases de Datos y Seguridad (8h): Integración con bases de datos relacionales, manejo de variables de entorno y autenticación básica mediante tokens.
  • Módulo 4: Proyecto Práctico (4h): Creación y despliegue de una API RESTful para manejo de un inventario. Esta API debe integrarse con clientes web o móviles.
